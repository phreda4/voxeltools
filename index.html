R3 Tools Suite

Internal development tools for graphics and animation processing.

3img2vox

Construct voxel models by intersecting 2D silhouettes from orthographic views.

dae2r3a

Collada (.dae) to R3a converter. Extracts skeletal structures and animation data.

glb2r3a

GLTF/GLB binary parser. Extracts skinning information directly from binary buffers.

voxel editor

Integrated voxel editing interface for modifying voxel models.

img2vox

Single-view image to voxel converter, ideal for quick 2D-to-3D asset prototyping.

vox2ssa

Converts voxel models into sprite-stacking assets (.ssa) for retro r3 rendering.
